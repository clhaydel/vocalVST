Panel-finish textures for the military-hardware UI. All derived from ambientCG (https://ambientcg.com),
licensed **CC0 1.0 Universal** (public domain). Only masks / relief / colour are used; the panel colour,
lighting and layout are drawn in code (`src/gui/PanelFinish.cpp`).
