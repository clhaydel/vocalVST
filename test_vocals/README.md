# Test vocals

Drop your own dry vocal takes (spoken, sung, screamed, whispered) in this folder as `.wav`;
`scripts/render_presets.sh` renders every factory preset against every file here.

Included:
- `synth_*.wav` — deterministic synthetic voices (glottal-pulse source + formant cascade) generated by
  `hv_cli gen-vocals`: spoken, sung (vibrato), screamed (high f0, jitter/shimmer, aspiration, pitch breaks), whispered.
- `cmu_spoken_*.wav` — real read speech from the CMU ARCTIC databases (speakers bdl, slt, rms; utterance a0003),
  resampled 16 kHz -> 48 kHz. Free for any use; see `CMU_ARCTIC_COPYING.txt`.

Real screamed / harsh-vocal takes are the most important material for judging this plugin — add some.
